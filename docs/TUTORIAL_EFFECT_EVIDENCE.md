# 教程中的改善，与当前实验为什么不同

2026-11-06重新读取两篇飞书页面公开HTML，并复核其中可见的生成与训练代码。本文区分可复核代码、预期输出和实际实验成绩。

## 能确认的内容

两篇使用较早的 `Qwen/Qwen-7B-Chat`；本项目使用 `Qwen/Qwen2.5-7B-Instruct`。后者原有的中文解释、指令遵循和健康常识能力已较强。同样的模板微调能改变回答风格，但未必能提高这个更强基座的答案质量。

[第一篇](https://lcnipys9u0xh.feishu.cn/wiki/N9T2wtMzwiryVXklxHPcxlfNnIb)描述症状采集、分诊、检查、报告和拒答，并列出分诊85%、高风险处理95%等验收目标。目标不能当作本项目实测成绩。默认生成路径主要是内置知识表、槽位和句式组合；列出的公开语料和可选LLM扩写，不等于默认运行时已经使用这些来源。

[第二篇](https://lcnipys9u0xh.feishu.cn/wiki/LC0swKCUZiTBsdkVDaWcmkqqnGh)的6000条由教学种子和循环模板生成，随机打乱后切成训练5600、验证400。训练loss下降的展示位于“预期输出”上下文；下降说明拟合训练目标，不直接证明新病例的回答优于基座。

## 第二篇代码的重复与验证泄漏

从页面保存的Python文本中只解析字面常量，再在本地重建循环和seed=42的随机切分。没有执行下载的远程代码，没有运行教程模型训练。药品答案用不同占位符替换，只保留各自身份和重复关系。

| 类别 | 生成记录 | 不同问答对 |
| --- | ---: | ---: |
| 知识 | 2400 | 30 |
| 问诊 | 2400 | 16 |
| 拒答 | 1200 | 3 |
| 合计 | 6000 | 49 |

拒答模板和槽位都按同一个下标取模，长度也同为3，因此只产生3种组合。400条验证记录中的45种不同问答，全部也存在于训练中，即400/400验证记录可在训练找到相同问答。这样较容易得到较低验证loss，但测到的很大部分是对已见问答的拟合，不能替代按病例分组、未见问法及独立知识的测试。

审计结果：[tutorial2-repetition-audit.json](../outputs/tutorial-audit/tutorial2-repetition-audit.json)。可见源码保存在 `outputs/tutorial-audit/tutorial2-gen_sample_raw.py.txt` 与 `tutorial2-build_instruction.py.txt`。这项复核没有证明教程的任何独立测试分数，也不能单凭重复数据推断未读取的测试如何产生。

## 读取范围与结论边界

公开HTML包含239个内容节点，标记仍有后续内容。继续读取接口返回Login Required，所以本次不能完整复核后半部分的全部评测代码和结果。保存的原始HTML、解析块、顺序文本与接口响应位于 `outputs/tutorial-audit/`，保留这项访问限制。

因此，可以复核其教学数据和训练路径；不能承诺照着做一定超过当前基座，也不能把预期输出或目标当作已验证提升。当前固定36题保留了更多正常解释、多轮信息更新和多要点检查，按病例隔离的数据验证也更难。此前微调把完整回答压缩成短追问、短拒答，部分任务改善的同时，普通知识、计算和明确行动反而退化。

本轮据此改为完整答案、可计算事实、当前/假设/否认/更正/恶化的成组情境，并筛选基模回答用于能力保留；所有新结果仍须在相同基座、提示、生成参数和原题规则下实际测量。
