# V2最佳adapter的36题评测复核

2026-11-01：用户完成V2最佳adapter的raw评测，以及与原基座、V1的两份对比。编码助手核对三组报告、重新计算逐题分数，并阅读V2全部36条回答；基座和V1逐题观察沿用此前已完成的复核。本记录为工程观察，尚未经专业医学审核。

结论：V2改善了部分普通建议和多轮信息利用，但要点通过数仅从V1的25/36变为26/36，原基座仍为31/36。部分分诊丢分来自同义表达漏匹配；同时报告题存在已知单位被当作缺失、数值方向矛盾等实际缺陷。因此尚不能证明V2整体优于基座，也不能仅由净增一题判定稳定提升。

## 数据与训练的解释限度

当前V2源数据及训练预检仍匹配原记录。新36题全部用户轮与源数据用户文本及related_questions按现有normalize逻辑无完全相同匹配；V2的36个完整输出也没有与实际8400条训练集任一assistant答案逐字相同。这不能证明没有短语记忆或语义重叠，多处尾句仍呈现模板迁移。

9000条候选实际来自300个知识/场景组，训练280组、验证20组；前缀与槽位不等于独立病例。训练报告解读1260条中，缺单位420、范围内420、范围外偏高300、偏低120。这个分布值得在后续数据设计中核查，但不能仅凭这些计数断言它导致了具体幻觉。当前种子脚本对范围外已有高低判断，不能声称所有训练异常都被写成“偏高”。

最终V2来自第150步，后续验证loss持续上升；验证loss选出的最佳已保存checkpoint不一定是生成回答质量最优的checkpoint。第150步之前缺少保存及验证，无法从现有文件比较25/50/100步；也不能由此断言只需降低学习率或再扩行数就会解决问题。

本轮保留题目、评分、summary、预测、manual_review.csv、数据和adapter，未把36题原文或修正答案加入训练。尚未进行专业医学事实审核、最终未见测试或真实自主多轮评测。拒答6/6、禁止模式0及要点分数均不构成临床安全或准确率。

## 后续方向

建议优先优化数据质量与训练策略：以单位、数值方向、已知/未知病史和急症行动为通用约束，增加不同信息组合与独立场景，减少统一尾句，避免针对36题原文补答案。数字和字段一致性可由工程检查辅助，医学建议仍需专业审核。

训练对照可增加第150步之前的验证与保存，明确早停和选模型规则，保留基座及当前V1/V2作为对照；保持数据与训练参数的变化有记录，分别判断数据和训练强度的作用。继续保留现有36题作为开发回归，并另留未用于迭代的场景验收。

若优先进入应用阶段，可搭建本地接口和聊天界面，提供基座/V1/V2切换及模型来源展示，将本轮结果作为开发记录。应用界面本身不代表模型质量达标。
