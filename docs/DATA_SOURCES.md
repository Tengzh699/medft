## 第一篇：项目24医疗问诊对话微调

原文：[医疗问诊对话微调](https://lcnipys9u0xh.feishu.cn/wiki/N9T2wtMzwiryVXklxHPcxlfNnIb)。

第1.3节介绍三种来源：公开医疗语料、经授权的脱敏问诊记录、大模型合成扩写。参考语料列有cMedQA2、MedDialog、CMID、cMedNLI等。

实际提供的 `build_dataset.py` 默认使用代码内的 `KNOWLEDGE` 示意知识表和规则模板：表中写入症状、起病时间、持续情况、伴随症状、科室、紧急程度、检查与建议；用 `itertools.product` 枚举槽位组合，并通过不同句式形成样本池，再采样得到目标数量。代码允许额外调用兼容接口做LLM扩写，该步骤可选。

流程：内置示意知识表 → 槽位与句式组合 → 五类任务样本 → 可选LLM扩写 → 脱敏、去重及质量过滤。

| 任务 | 比例 | 9000条目标数量 |
| --- | ---: | ---: |
| 症状采集 | 35% | 3150 |
| 分诊 | 25% | 2250 |
| 检查建议 | 15% | 1350 |
| 报告解读 | 15% | 1350 |
| 拒答 | 10% | 900 |

教程称清洗后为8028条。公开数据集被介绍为可选知识来源；默认示例生成代码中的内置表，不能等同于已经下载、抽取并审核过这些公开数据集。

## 第二篇：MedicalGPT风格医疗领域微调

原文：[MedicalGPT风格医疗领域微调](https://lcnipys9u0xh.feishu.cn/wiki/LC0swKCUZiTBsdkVDaWcmkqqnGh)。

第1步明确说明：为可复现教学，使用合成样例数据生成脚本，不接触真实患者信息。

`gen_sample_raw.py` 生成模拟来源文件：

- `encyclopedia.jsonl`：医学百科知识样例。
- `drugs.csv`：药品信息样例。
- `consult.jsonl`：问诊样例。
- `refusal_seed.jsonl`：拒答场景种子。

这些名称表示模拟的数据类别，不表示已经从百科网站、药品数据库或医院导入了真实语料。随后清洗脱敏得到 `cleaned.jsonl`，指令构建脚本通过知识种子扩写、问诊槽位组合和拒答场景轮转生成目标样本。

| 任务 | 比例 | 合成总量6000条中的数量 |
| --- | ---: | ---: |
| 知识问答 | 40% | 2400 |
| 问诊 | 40% | 2400 |
| 拒答 | 20% | 1200 |

代码先生成总计6000条，再切出400条验证数据，实际训练5600条。文中概览的“训练6000+验证400”与该代码口径不同，应以运行脚本的实际计数为准。
