## smoke-001：空腹血糖的时间含义

- 记录日期：2026-10-29。
- 来源：用户手动运行 `python -m medft chat --adapter outputs/v1-smoke/adapter`。
- 基座：Qwen2.5-7B-Instruct，提交版本 `a09a35458c702b33eeacc393d103063234e8bc28`。
- adapter：`outputs/v1-smoke/adapter`，训练5步。
- 问题：什么是糖化血红蛋白？它和空腹血糖有什么区别？

用户贴出的回答正文（聊天程序另附免责声明）：

> 糖化血红蛋白是血液中的葡萄糖与血红蛋白结合形成的一种物质，反映的是过去2-3个月的平均血糖水平。空腹血糖是反映的是过去1天左右的血糖水平。

观察：前半部分对糖化血红蛋白时间范围的概括基本合理；“空腹血糖反映过去1天左右”不准确，也存在“是反映的是”的重复表达。

供专业复核的修订方向：糖化血红蛋白反映近2～3个月的平均血糖情况；空腹血糖通常是在至少8小时未摄入热量后，采血当时测得的血糖浓度，并非过去一天的平均值。两项指标的时间范围与解读方式不同。

当前状态：待专业人员复核，尚未形成审核通过的训练样本。此题暂存为开发中的错误案例，不修改已固定的训练数据和12道独立评测题。

2026-10-29补充基座对照：用户按指引运行 `python -m medft chat --base`，输入相同问题。基座回答包含：

> 糖化血红蛋白反映的是较长时间内的平均血糖水平，通常为2-3个月，而空腹血糖只反映的是某一时刻的血糖水平。

基座在这处时间概念上回答正确，当前试跑adapter则出现“过去1天左右”的错误，构成此案例中的事实性退化证据。该观察限于当前配置和此题，不能仅由一例判定模型整体医学能力或通用能力退化。

基座还额外给出HbA1c与空腹血糖的诊断分类阈值，未注明采用的指南和适用条件；专业复核需统一分类口径，并检查诊断确认和检测条件等说明。基座整段回答仍不能直接用作审核通过的训练答案。
