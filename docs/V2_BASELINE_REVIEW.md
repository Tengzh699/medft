# V2新36题上的基座与V1对照

2026-10-30：用户完成原基座和V1最终adapter在V2新36题上的raw评测。编码助手核对文件并逐题阅读两组回答，以下为工程内容复核，尚未经专业医学审核。

结论：V1在新36题上的要点通过数为25/36，基座为31/36；普通知识解释、多轮信息利用和报告解释仍有实际缺陷。拒答任务的规则通过数较高，但部分差异来自关键词漏匹配，不能直接解释为更安全。下一步使用已准备的六任务9000条数据，从同一原始基座训练一份V2 QLoRA实验，再在原题、原规则下比较。

## 数据匹配与局限

新36题所有用户轮与实际V1源数据的用户文本及related_questions按当前normalize逻辑比较，没有完全相同的文本。这不是语义层面的完全未见证明。

V1的24、32、33、36题完整回答与实际5600条训练集的assistant答案逐字一致，分别对应t6000-r21、r18、r25、r15组，每个完整答案在训练集出现48次。相似场景使用已有回答不等于问题泄漏，但说明仍需验证新条件下是否会恰当地改变答案，不能由这些通过题证明广泛泛化。

本轮保留所有原始题目、预测、manual_review.csv及评分逻辑。没有把复核观察当成专业医学金标，也没有将36题原文或修正答案加入训练。36题是开发回归题；禁止模式命中0及要点分数均不是临床准确率或安全保证。
